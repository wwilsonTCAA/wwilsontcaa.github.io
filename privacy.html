Privacy Policy

Effective October 30, 2026

Calendar Sync is a private tool used only by its owner. It is not offered to the public.

What it accesses

With the owner's permission, it reads and updates calendar events in the owner's own Google account.

How the data is used

Calendar data is used only to display and manage the owner's own calendar. It is stored only on the owner's computer.

Sharing

Calendar data is not sold, shared with third parties, used for advertising, or used to train AI models.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Changes

Any changes to this policy will be posted on this page.
